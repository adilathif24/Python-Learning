# Python APIs and External Data Track

## Learning order
1. [Day 24 — CSV and JSON](../days/DAY-24-CSV-and-JSON.md) for structured data.
2. [Day 26 — Virtual Environments and Dependencies](../days/DAY-26-Virtual-Environments.md).
3. [Day 34 — APIs and External Data](../days/DAY-34-APIs-and-External-Data.md).

## Checklist
- Request timeout is set.
- HTTP and network errors are handled appropriately.
- JSON is parsed and its required fields/types are validated.
- Secrets are stored outside source control.
- Retries are bounded and respect service limits.
- Offline validation tests do not depend on network availability.

Start with the offline examples in Day 34; run public network requests only when internet access is available.
