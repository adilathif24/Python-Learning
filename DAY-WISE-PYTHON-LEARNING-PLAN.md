# Python Learning — Day-Wise Master Plan

## Purpose

This repository is a practical Python curriculum organised like a technical-interview preparation programme. Learn in order, build working code, test it, and explain your decisions clearly. Python Core, OOP, exceptions, files, modules, DSA and interview preparation are separate tracks.

## Mandatory lesson template — every topic, every day

1. **Definition** — accurate technical definition in simple English.
2. **Detailed explanation** — how it works step by step, with a dry run.
3. **Syntax and rules** — general syntax, parameters, return behaviour and constraints.
4. **Why / where / when** — purpose, real-world usage, when to choose it and when not to.
5. **Five complete examples** — each has the question, full runnable code, expected output and explanation.
6. **Five practice questions** — each has requirements, sample input/output, full solution code and explanation.
7. **Five real-world applications** — explain where each is used, when useful and how the concept is applied.
8. **One main real-world project** — purpose, user story, design, complete runnable code, setup/run instructions, sample run, normal/boundary/invalid test cases, limitations and improvements.
9. **Common mistakes** — incorrect pattern, why it fails, and corrected code.
10. **Interview preparation** — likely questions, ready-to-say answers, follow-ups and recruiter-style evaluation criteria.
11. **Revision** — quiz with answer key, recap and independent challenge.
12. **Completion tracking** — status, evidence of practice, blockers and next topic.

Keep content concise and relevant. Remove duplicated explanations, filler, unrelated topics and broken links. Do not remove useful learning notes without checking them first.

## Progress status definitions

- **Covered:** appeared in a lesson or practice session; not proof of mastery.
- **Ongoing:** currently learning or needs correction/revision.
- **Completed:** examples run, tasks attempted, code explained, quiz passed and project tested.
- **Next:** next lesson to study.
- **Planned:** curriculum item not yet taught.

Never mark a topic Completed just because a Markdown file exists.

## Separate tracks — do not mix lesson files

- **Python Core:** core/ and days/ — language fundamentals and practical scripting.
- **Object-Oriented Programming:** oop/ — classes, objects, methods, encapsulation, inheritance, polymorphism, abstraction and composition.
- **Exceptions:** exceptions/ — errors, exception types, raising, handling and custom exceptions.
- **Files and data formats:** files/ — text files, paths, CSV, JSON, encoding and safe resource handling.
- **Modules and packages:** modules/ — imports, package structure, entry points and reusable code.
- **Data Structures & Algorithms:** dsa/ — complexity, patterns, data structures and algorithms.
- **Interview preparation:** interview/ — recruiter-style answers, coding rounds, project walkthroughs and mock interviews.

## Recruiter-style quality bar

For every project, explain the problem, intended user, inputs/outputs, design choices, validation, errors, tests, limitations and next improvement. Do not claim a learning exercise is production-ready. A topic is complete only after independent practice and review.
