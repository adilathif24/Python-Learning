## Topics
- `import`, `from ... import ...`, aliases
- `if __name__ == "__main__"`
- Package layout and avoiding circular imports
- Virtual environments and dependency specification
- Module responsibility, testability and reusable APIs

## Completion criteria
Build a small multi-file app where business logic lives in one module, the command-line entry point is in another, and unit tests import the business functions without triggering interactive behavior.
