# Day 03 — Conditions

> **Status:** Previously practised in learning sessions; this separate day file organises the lesson scope. Complete the full study pack before marking mastery.

## Learning goals
- `if`
- `elif`
- `else`
- nested conditions
- logical operators
- boundary checks and branch order.

## Required lesson structure
1. Definition and detailed explanation in simple English.
2. Why, where and when to use each concept, including when not to use it.
3. Syntax, rules and a dry run.
4. Five complete worked examples: question, full runnable code, expected output and explanation.
5. Five practice tasks: requirements, sample input/output, complete solution code and explanation.
6. Common mistakes and edge cases.
7. Interview questions and answers.
8. One real-world mini-project with complete runnable code, setup, sample output and tests.
9. Revision quiz, answer key and independent challenge.
10. Update progress only after practice and review.

## Real-world project
**Project idea:** Build an eligibility checker.

The project must have complete runnable code and tests for normal, boundary and invalid inputs.
